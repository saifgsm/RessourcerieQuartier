# Ressourcerie Quartier

**Projet réalisé en équipe avec Roland Dansou.**

> 👉 Le code du projet se trouve sur le dépôt principal : **[rolanddansou/RessourcerieQuartier](https://github.com/rolanddansou/RessourcerieQuartier)**

## Description

Application web pour une ressourcerie de quartier : gestion des dons d'objets, ateliers, planning et espace de gestion.

## Technologies

- **Backend** : Django 5.2 (Python 3.12)
- **Frontend** : React 19, TypeScript, Vite
- **Base de données** : SQLite (développement)

## Ma contribution

- Gestion des dons et des objets.
- Navigation de l'application et page des ateliers.
- Travail en équipe avec branches de fonctionnalité, pull requests et branche `staging`.
